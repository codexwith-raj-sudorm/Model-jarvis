# Model-jarvis → JARVIS

**JARVIS** — a local-first, voice-first AI assistant for Android.
"Hey JARVIS" → ask anything → optional internet lookup (free, key-less
sources only) → answer by voice. The LLM (llama.cpp, GGUF), STT/TTS
(sherpa-onnx) and wake word all run fully on-device.

- 📁 **The buildable project is the [`jarvis/`](jarvis/README.md) folder** —
  open *that* in Android Studio.
