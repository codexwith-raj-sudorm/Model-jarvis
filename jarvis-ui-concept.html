Design system

Palette Deep space #0B1220 @ 82% + blur · Arc cyan #22D3EE · Soft cyan #67E8F9 · Text #D6E4F0 · Dim #9FB3C8 · Danger #F87171
Type HUD/meta: monospace 10–11px, +0.1em tracking, UPPERCASE · Conversation: sans 15–17px, 1.45 line height · Question cards tinted cyan, answers neutral
Motion Summon: edge-glow sweep 1.1s, banner fade 2.2s · Rings: 14s / 9s / 5s (thinking: 3.5s / 1.8s) · Core pulse 2.6s (thinking 1.1s, speaking 1.3s) · All easing cubic-bezier(.2,.8,.2,1)
Layout anatomy status row (top, monospace) → subtitle cards (center-bottom, stacked, fade upward) → state word → THE ORB (bottom center) → control pills. Keyboard slides up only on request.

State machine (one orb, four moods)

SummonEdge of screen glows cyan once + "◈ Hey JARVIS ◈" banner fades through — the *confirmation blink* that it heard you. 450ms later the HUD is live and the mic is already open.
ListeningOrb calm, slow rings, sonar pings radiating. Live partial transcript floats above in large text with a blinking caret. Waveform bars inside the core react to your voice.
ThinkingRings spin up (3–4×), core breathes fast and shrinks slightly. Your question docks into a cyan question card. Tool activity appears as a pill that flies in: spinner → ✓ ("🔧 weather → open-meteo").
SpeakingCore pulses at speech rhythm, waveform dances. The answer types in as a neutral subtitle card with a source chip ("⛓ source: Open-Meteo"). Old cards stack and dim — a transcript, not a chat wall.
Idle > 45sHUD collapses to just a small dim orb in the bottom corner (still listening for the wake phrase); full HUD re-expands on voice or tap.

Why subtitle cards, not chat bubbles

A voice assistant's overlay is a transient surface — you glance at it, not read it. Left/right chat bubbles force you to parse a conversation; centered subtitle cards read like film captions and keep the reactor as the single focal point. History is one tap away (expand icon), but never the default view.
Trust affordances baked in: the 🌐/✈ web state is always visible in the status row; every web answer carries its source chip; the fetch log is one long-press away. Privacy isn't a setting here — it's part of the visual grammar.
